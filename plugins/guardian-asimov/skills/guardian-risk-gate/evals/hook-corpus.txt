# Test corpus for the guardian-gate.sh hook
# Format:  CATEGORY@@EXPECTED@@COMMAND     (EXPECTED = ASK or PASS)
#
# The tests ONLY feed the command text to the hook; nothing is executed.
# EXPECTED describes the CURRENT known behavior. If a LIMIT case changes
# (because the hook was improved), the runner flags the difference: update
# the row.
#
# Categories:
#   TP           operation documented as critical; must ask for confirmation
#   VARIANT      simple variant of a documented operation; must ask for confirmation
#   FIXED        harmless case that used to trigger and no longer does
#   CONTROL      normal command; must not ask for confirmation
#   LIMIT-FN     known limitation: destructive command the hook does NOT detect
#   LIMIT-FP     known limitation: harmless command the hook DOES flag (regex over text)
