# Corpus de pruebas del hook guardian-gate.sh
# Formato:  CATEGORIA@@ESPERADO@@COMANDO     (ESPERADO = ASK o PASS)
#
# Las pruebas SOLO alimentan el texto del comando al hook; no ejecutan nada.
# ESPERADO describe el comportamiento ACTUAL conocido. Si un caso LIMITE cambia
# (porque se mejoró el hook), el runner marca la diferencia: actualizá la fila.
#
# Categorías:
#   TP           operación documentada como crítica; debe pedir confirmación
#   VARIANTE     variante simple de una operación documentada; debe pedir confirmación
#   CORREGIDO    caso inocuo que antes disparaba y ya no
#   CONTROL      comando normal; no debe pedir confirmación
#   LIMITE-FN    limitación conocida: destructivo que el hook NO detecta
#   LIMITE-FP    limitación conocida: inocuo que el hook SÍ marca (regex sobre texto)
